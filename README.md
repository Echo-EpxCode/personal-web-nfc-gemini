# Premium Personal Portfolio & NFC Review Card System (Frontend Prototype)

A professional personal portfolio website and admin dashboard built with HTML5, CSS3, Bootstrap 5, Bootstrap Icons, Vanilla JavaScript, and SweetAlert2.

## Local Setup Instructions

1. Place the entire `personal-portfolio` folder inside your XAMPP `htdocs` directory (e.g., `C:/xampp/htdocs/personal-portfolio`).
2. Start Apache via the XAMPP Control Panel (no database or PHP required for this frontend-only phase).
3. Open your browser and navigate to: `http://localhost/personal-portfolio/`.
4. Access the frontend-only admin dashboard at: `http://localhost/personal-portfolio/admin/`.
